# 从时本 2.0.0 升级到 2.0.1

本次只优化界面和应用图标，不增加功能，不修改数据库结构或记录格式。

正式安装包必须满足：
- 包名保持 cn.goff.shiben。
- versionCode 从 3 增至 4，versionName 为 2.0.1。
- 继续使用 V2 的同一正式签名证书；私钥留在用户 Mac。
- 通过两代正式 APK 的实际覆盖安装和数据保留验收后才交付。

## 安装方式

直接打开新版正式 APK，按 Android 提示更新已有的时本。不要先卸载旧版，不要清除应用数据。如果提示签名不一致或无法更新，请停止，不要以卸载重装绕过问题。

升级前也可以使用应用已有的“导出记录”或“本地存储与备份”保存一份可读副本。外部 Markdown 是可读备份，并非应用内自动恢复包。

验收应核对专注记录、任务、手动进度、历史快照、每日 Markdown、设置及暂停中的计时；Debug 升级测试不替代正式包验收。当前具体结果以对应版本的测试报告为准。
