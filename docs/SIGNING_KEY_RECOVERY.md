# V2 正式签名保管

1.0.1 的正式私钥不可用。历史公开证书位于 `history/1.0.1/RELEASE_CERTIFICATE.pem`，它不能用来签名或恢复私钥。

V2 正式签名身份已在用户批准后，在用户自己的 Mac 上创建和保管；密码由用户本地输入。云端没有创建、读取或收到这个正式私钥。公开证书见 `SHIBEN_V2_RELEASE_CERTIFICATE.pem`，SHA256 为 `af1c11b14290abcd0aa95dfa3284ce931a822751f2780293f0aab9c90cce59d5`。不要把私钥、密码、访问令牌加入 Git、Library、聊天或普通源码包。

请在自己的密码管理器保存密码，并亲自将加密私钥复制到另一份受控加密备份。验证备份可读后记录可公开的证书 SHA256 指纹；源码及 APK 不能替代私钥备份。

V3 必须复用 V2 私钥、保留相同包名、增加 versionCode。签名丢失后无法保证原地升级，因此正式证书应长期固定。
