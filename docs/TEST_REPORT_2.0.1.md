## 本轮发现并修复的问题

1. 320dp的导出格式按钮被截字：改为真实宽度下的自动字号，窄屏或大字号用纵向格式选择。
2. 200%字号的长页面标题超出两行：使用响应式字号保证完整标题。
3. 今日页总览过高：改为同一张半透明卡内的紧凑任务行；4项任务与更多入口在正常高屏完整显示。
4. 弹窗关闭后浅色系统栏图标偏淡：重新获得窗口焦点时恢复清晰的系统栏样式。
5. 新增的不定进度动画与后台PNG绘制争抢CPU：移除无必要动画，只显示真实进度，未知总数时保持空轨道；删除重复的0/0文案。

第5项做了同机同数据对照：早期2.0.1候选在241709毫秒观察窗口结束时仍RUNNING 0/1；去除动画后的候选PNG Job在4016毫秒完成，4251毫秒出现可保存控件。没有修改导出线程优先级、数据库或文件内容。后台无预览动画的16页PNG/跨日ZIP对照129项也通过。
