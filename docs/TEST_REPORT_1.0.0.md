# 专注账本 1.0.0 测试报告

本报告记录 2026 年 10 月 3 日云端构建的实际验证范围。已生成签名原生 Android APK，纯逻辑、存储契约与 Android 10 原生集成测试通过；用户的 realme GT6 未参与测试，不能据此保证该机型的后台提醒准时性。

## 已通过

1. 构建与静态检查
   - Android SDK35、BuildTools35.0.0、AGP8.9.2、Gradle8.11.1、OpenJDK21.0.2。
   - Debug、Release、独立 Android 测试 APK 均成功构建。
   - 最低 API26，目标 API35；Release 无 debuggable 属性，运行时不包含原生库和第三方 SDK。
   - Lint：0 个错误、3 个仅中文界面的国际化文案警告；没有隐藏失败检查。
   - 仅声明 POST_NOTIFICATIONS、VIBRATE、FOREGROUND_SERVICE、FOREGROUND_SERVICE_SPECIAL_USE、SCHEDULE_EXACT_ALARM、RECEIVE_BOOT_COMPLETED。无网络、应用使用情况、无障碍、位置、联系人、图片、麦克风权限。
   - 关闭系统自动云备份与设备迁移规则。

2. 纯 Java 单元测试
   - 65 个真实 JUnit4 测试：全部通过，0 失败、0 跳过。
   - TimerEngine 38 项、Session 11 项、DailyTotals 16 项。
   - 包含至少15分钟/5分钟步进、仅一轮活动计时、暂停排除、提前结束实际时长、到点封顶、完成幂等、序列化恢复、同次启动进程恢复、重启保守结束、前后调时、跨午夜、时区改变、夏令时23/25小时与跳过日期、溢出与防御性复制。
   - 另含200个完整计时的随机状态与调时转换守恒检查，包含在上述65项中。

3. 存储与导出辅助检查
   - 25 个实际 Java 辅助方法断言通过：任务重复/一次性规则、CSV转义、公式注入保护、序列化、时间归属等。
   - 13 个 Python SQLite 契约检查通过：运行从源码提取的建表 SQL 并模拟快照保留、唯一记录、删除墓碑与事务回滚。
   - 这13项是 SQL 契约检查，不冒称 Android SQLite 方法的运行时实测。

4. Android 10 API29 原生集成
   - 官方 AOSP x86_64 模拟器，软件CPU1核、1536MB内存；无硬件虚拟化加速。
   - 最终自定义 Instrumentation 运行：34项全部通过。
   - 原生Activity与中文品牌、6分类/任务、无网络权限、备份关闭。
   - 真实秒级投入、暂停期间不增时、暂停状态持久化、第二计时拒绝、继续与提前结束仅记录实际时间。
   - SQLite完成事务/唯一ID幂等、空闲状态清除、手动补记、更正标志、历史/未来时间边界、重复投入拒绝、删除墓碑防复活。
   - Markdown、CSV、JSON实际方法；CSV公式注入保护。
   - 将应用自己的Activity移到后台后，在不调用UI刷新/主动reconcile的条件下结束计时，并观察到完成通知已发布、仅一条完成记录、完成状态仍未自动勾选。
   - 统计和设置页面的真实导航。
   - 到点测试使用“已投入14分55秒”的测试APK专用夹具，保持计划15分钟，再等待真实5秒后台到点。夹具和反射代码仅存在独立测试APK，不进入交付应用。它不是手机连续15分钟息屏耐久测试。

   - 项目独立 Git 仓库有可回退提交，源码ZIP压缩完整性通过，Git bundle已验证可克隆完整历史。

   - 交付APK使用独立RSA3072位密钥，apksigner验证v2/v3签名有效。
   - 签名证书SHA256：21448561864130135118013f194f94187e8ad887086351c395da230193996261。
   - 签名Release APK已在Android10安装并启动，包标志没有DEBUGGABLE；432×960首启与开始计时弹窗、运行中倒计时截图已逐像素查看，中文、卡片、计时与暂停/结束按钮、底部导航正常。正式签名版通过真实点击开始了一轮25分钟计时，并点击暂停、统计与设置导航；这些页面截图已检查。Release冒烟日志未见本应用FATAL EXCEPTION。

## 测试中遇到的问题与修复

- 原始UI遗漏0时长完成记录、全分类归档时无法编辑旧记录、秒以下记录无法只改名称：已修复并重新编译、测试、Lint和打包。
- 最初测试器尝试向其他应用注入HOME按键，被Android拒绝；改为本应用合法的moveTaskToBack API，不增加应用权限。最终34项通过。
- API35模拟器无KVM，初次启动出现系统Watchdog重启；约10分钟后启动并安装应用，但测试连接后来断开、无完整结果，因此不计作API35运行时通过。
- API29软件模拟器曾出现Android System UI无响应弹窗。这是模拟器系统组件，不是本应用的崩溃证据；不能据此隐瞒或承诺真实设备性能。

## 建议在手机上验证

安装后先允许通知，按需允许“闹钟和提醒”；开启一轮15分钟任务，锁屏等待到点，再确认只有一条记录、15分钟封顶、任务未自动勾选。第二轮暂停数分钟后继续并提前结束，核对实际时长不含暂停。最后复制当天Markdown并导出CSV。强行停止的系统限制无法通过额外权限绕过。

这份报告的“通过”只覆盖以上明确执行的检查，不表示所有设备/权限组合均通过。
