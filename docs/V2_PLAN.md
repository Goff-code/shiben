# 时本 2.0 制作与验收

获批的原生界面参考见 `design/v2`。设计图是参考，Android 系统文件/通知权限对话框采用系统实际外观。

- 三页：专注、任务、今日；设置/历史/导出只经今日底部“更多”进入。
- 专注主页面不使用纵向滚动；保留现有单调时钟、持久状态、暂停排除和保守重启计时逻辑。
- 用户手动更新任务进度；完成计时从不改进度。优先级按剩余权重折半、最后一项取剩余。
- SQLite 增量迁移；按天保存任务名称、进度、次序及权重。旧版未知历史明确标记。
- 持久、原子写入每日 Markdown；PNG 用离屏完整列表、多页/多日期 ZIP；导出不阻塞主线程。
- 无网络权限、无广告/跟踪、无收费依赖。云端构建未签名 release；debug 签名仅云端临时测试。
- release 私钥由用户 Mac 后续生成和保管，本代码库不保存任何私钥。V3 必须同包名、同 release 证书、较大 versionCode；升级不得卸载或清除数据。

验收包含纯 Java 单元、SQLite 迁移、Android 集成及可行的模拟器实际界面；真机 realme GT6 / UI7.0 的后台行为须用户验证。
