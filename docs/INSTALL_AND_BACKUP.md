# 时本 1.0.1：安装与备份

记录每一份注意力，投资你想成为的人。

## 安装本次新版

本次安装文件是 **时本-1.0.1.apk**。这是实际重新构建并完成正式签名的新版，桌面名称为“时本”，首页为“今天，你把注意力投向了哪里？”。不是把旧 APK 改文件名。

1. 把 APK 保存到 Android 手机（Android 8.0 或更高）。
2. 在文件管理器中点开 APK，根据系统提示决定是否允许这个来源安装应用；完成后可关闭来源安装权限。
3. 打开“时本”。按需在“设置”允许通知及“闹钟和提醒”，提高到点提醒可靠性。应用不会请求自行安装其他软件。

首次安装可能被 Android 标为不来自应用商店；这不等于已被上架或经过商店审核。遇到系统安全阻止，请自行检查来源，不要盲目绕过。

## 与旧版同时存在

- 新版安装身份：`cn.goff.shiben`，版本 1.0.1 / versionCode 2。
- 旧版安装身份：`cn.focusledger`，名称“专注账本”。
- 原签名私钥在制作环境重置后目前无法找到，不能仅凭 APK 或源码恢复。新版因此使用独立包名和新的签名身份。
- 两个应用可以各自保留。安装时本不要求卸载、清除或覆盖旧版；不要为改名而删除旧数据。
- **时本会建立自己的空记录库，不会自动继承旧版记录。** 两个应用的数据库虽同名 `focus-ledger.db`，但位于不同的应用私有目录。
- 当前 CSV/JSON 只支持导出留存，**没有 JSON 自动导入/恢复**。把旧数据导出并保存，并不意味着它已经迁入时本。

## 数据留存

“统计”可复制当天 Markdown；“设置”可导出全部 CSV 和 JSON 数据包，保存到你主动选择的位置。建议先从旧版导出，再开始使用新版。

卸载应用或清除应用存储会删除它的本地记录。系统自动云备份和设备迁移已关闭；不要把重新安装当作恢复数据的方法。

## 提醒与设备限制

拒绝通知仍可使用记录，但不能保证通知、声音或震动。未允许精确闹钟时，息屏提醒可能延迟，返回时会校正，计入时间以计划时长封顶。realme 等机型还可能限制后台活动；没有在用户的 realme GT6 上实测。

强行停止会取消提醒，重新打开后按持久状态校正。设备重启会结束未完成的一轮，并仅保留最近保存检查点前的有效投入，不猜测关机期间的时间。
