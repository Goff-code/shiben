# 时本 2.0：安装、升级和备份

## 当前交付

- 版本 2.0.0 / versionCode 3，安装身份 `cn.goff.shiben`，最低 Android 8.0 / API26。
- 云端生成的是 **未签名 release APK**，不能直接安装。云端 debug 证书仅用于一次性模拟器测试，不能成为正式签名身份。
- 1.0.1 的签名私钥已丢失；它的公开证书只保留为历史资料，无法用它恢复签名。
- 新的长期 V2 release 私钥必须在用户 Mac 上经明确批准后生成，由用户自行保管。私钥和密码不得放入聊天、源码、GitHub、Library 或交付包。
- 同包名不同签名的 V2 不能直接覆盖已安装的 1.0.1。用户已决定自行处理旧版卸载；执行前应先从旧版导出数据。我们不会对用户手机卸载或清除数据。

## V3 及以后

1. 保持 `cn.goff.shiben`。
2. 使用 V2 同一正式签名证书；不要重新生成签名。
3. 递增 versionCode，正常覆盖安装，不卸载、不清数据。
4. 每次发布实际运行升级留存测试，验证任务、进度、每日快照、专注记录、设置和 Markdown 均保留。测试证书验证不能代替正式证书一致性核验。

## 历史与备份

- SQLite 是原始记录源；每天 Markdown 保存在应用内部持久目录，不自动过期，写入采用原子替换。
- 今日 / 更多 / 本地存储与备份可选择外部文件夹，让每日 Markdown 自动同步过去。
- 导出支持日、月、年、自定义起止（包含两端）及全部记录；Markdown 可复制或保存；多日 PNG 或超长列表以 ZIP 保存完整分页图片。
- 卸载、清除应用数据会删除应用内部记录。外部所选文件夹是否保留由系统及提供方决定，应自己确认文件可打开并保有额外副本。
- Markdown/PNG 为可读留存；本版没有自动导入恢复功能。
- 旧版未知的历史名称、优先级、权重和进度不从当前配置倒推；可证明的原记录保留，缺失信息标记未知。
- 任务列表跨天保留，每天进度从0%重新开始，前一天进度不变。
- 若系统日期回退到已封存日期，任务/进度编辑会暂时拒绝并提示检查日期，计时与读取/导出仍可用。这优先保护既有历史；本版不提供修改已封存日期的修复/合并工具。

## 手机验证

在 realme GT6 / UI7.0 上由用户测试通知、声音/振动、锁屏至少15分钟、后台限制和重启。模拟器通过不代表该机型已通过。通知/精确提醒拒绝时功能降级会提示；强行停止后不能保证提醒。
