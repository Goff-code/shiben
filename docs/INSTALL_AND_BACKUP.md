# 时本：版本、安装与备份

记录每一份注意力，投资你想成为的人。

## 当前交付状态

- 时本 1.0.1 是已更新品牌与文案的源码版本（versionCode 2）。
- 目前没有可安装的时本 1.0.1 正式 APK。此前交付的“专注账本-1.0.0.apk”仍是旧名称、旧文案的版本，不能把它改文件名后当作新版。
- 制作环境重置后，原签名私钥目前无法找到。原私钥不在源码 ZIP 或 Git 历史中，无法仅凭旧 APK 恢复私钥。
- 本次未创建替代签名密钥。若原密钥恢复，可据此构建同包名、同签名的更新；在实际构建与验证前，不承诺覆盖更新成功。

## 已有旧版 APK 的安装

把此前收到的“专注账本-1.0.0.apk”保存到 Android 手机，在文件管理器中点开，按系统提示安装。安装来源权限由你在手机上选择，完成后可关闭该来源权限。应用不会请求自行安装其他软件。

第一次使用可在应用“设置”中允许通知；按需打开“闹钟与提醒”权限，提高息屏到点提醒可靠性。不给权限仍可记录时间，但不能保证通知、声音或震动。realme 可能另有限制后台运行的系统设置，请以手机实际菜单为准。不要把应用强行停止当作普通返回桌面。

## 数据与更新边界

本次源码保持包名 cn.focusledger、数据库 focus-ledger.db、JSON 格式标识 focus-ledger-backup、数据库结构和计时逻辑不变。这些源码检查不等同于完成了安装覆盖测试。

“统计”可复制当天 Markdown；“设置”可导出全部 CSV 和 JSON 数据包。文件保存在你主动选择的位置。JSON 目前用于数据留存，本版本没有自动恢复导入。

卸载或清除应用存储会删除本地记录。先导出，再决定是否卸载。不同签名的重建 APK 不能直接覆盖旧版；不要为改名或更新而盲目卸载。若未来选择不同包名的独立版本，它会另建本地数据，旧数据不会自动迁移。

## 源码和 Git 历史

- “时本-1.0.1-源码.zip”：项目源码、测试和构建说明。
- “时本-1.0.1-源码历史.bundle”：独立 Git 仓库的完整历史，包含原版开发记录。恢复示例：

  git clone "时本-1.0.1-源码历史.bundle" shiben
  cd shiben
  git log --oneline

Git bundle 不需要 GitHub 账号或远程仓库。下载并保存到自己的备份位置，才能让它不依赖当前制作环境。仅云端本地 Git 不能替代异地备份。

SDK、缓存、应用数据与签名私钥没有进入源码或 Git 历史。源码备份与签名身份备份是两件事。后续正式签名与更新方式需要在打包前明确。
