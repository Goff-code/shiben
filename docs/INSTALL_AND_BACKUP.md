# 安装与备份

## 安装

把“专注账本-1.0.0.apk”保存到Android手机，在手机文件管理器中点开，按系统安装提示操作。安装来源权限由你在手机上选择，安装完成后可关闭该来源权限。应用不会请求自行安装其他软件。

第一次使用可在应用“设置”中允许通知；按需打开“闹钟与提醒”权限，提高息屏到点提醒可靠性。不给权限仍可记录时间，但不能保证通知、声音或震动。realme可能另有限制后台运行的系统设置，请以手机实际菜单为准。不要把应用强行停止当作普通返回桌面。

## 本地数据

“统计”可复制当天Markdown；“设置”可导出全部CSV和JSON数据包。文件保存在你主动选择的位置。JSON目前用于数据留存，本版本没有自动恢复导入。

卸载或清除应用存储会删除本地记录。先导出，再决定是否卸载。使用不同签名的重建APK不能直接覆盖当前签名，勿为了更新盲目卸载。

## 源码和Git历史

- “专注账本-源码.zip”：可以直接查看与修改的全部项目源码、测试和构建说明。
- “专注账本-源码历史.bundle”：独立Git仓库的完整历史。恢复示例：

  git clone "专注账本-源码历史.bundle" focus-ledger
  cd focus-ledger
  git log --oneline

Git bundle不需要GitHub账号或远程仓库。下载并保存到自己的备份位置，才能让它不依赖当前制作环境。仅云端本地Git不能替代异地备份。

SDK、缓存与签名私钥没有进入源码或Git历史。后续由同一制作环境出同签名更新需要保留原签名密钥；独立自行重建时，请使用你自己的签名密钥并注意数据迁移。
