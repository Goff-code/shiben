# 专门涂鸦字形：代表性设计候选

2026-10-07，用户明确要求“帮我做成专门的涂鸦字”。此分支基于14f2b5c，在独立工作树做字形视觉设计。上一候选的树9598d83d20c58406862d2b40947cf3d4c5e04239未改。

当前只完成“时本／今日记录”和A−两个代表性透明字形，尚未批量生成其他等级，也没有替换生产导出模板或发布签名APK。所有新增绘制和资产均在androidTest中；main源码/资源及数据库、相册流程完全未变。

## 字形方案

- 标题整体重画为粗细不均的宽扁刷笔画、撕裂边缘和长笔锋，避免沿用普通书法字体。
- A−以青色主体、少量白色边笔、大块干刷飞白与斜向甩笔构成，不再使用规则多边形加细刮痕。
- 两个PNG均由内置图像生成工具基于用户原参考生成，透明背景开启；原始PNG字节原样打包，没有后期把背景或日期数据画进资产。
- A−第三版高alpha的A与减号完全独立，主体间隙在640像素宽显示时约11–15像素；极低alpha≤4/255的飞屑可接近。四边透明，笔锋未裁切。
- 默认查看器可能错误显示透明区RGB；使用Java2D黑底诊断显示真实alpha，并以Android Canvas实际输出为准。没有修改原PNG。

## 原生复现

测试入口：`lettering_study`，代码为`LetteringStudyChecks`与`LetteringStudyPoster`。运行在既有隔离API35模拟器，生产main APK不重装，只更新测试APK。

数据通过DaySnapshot输入，仍由原有业务模型和原生文字/圆环绘制：

- 主候选：2026-10-06 星期二、92.75%、3小时4分钟17秒、A−
- 动态对照：2026-10-07 星期三、91.25%、6小时8分钟14秒、A−
- 另保留A−第二版资产的内部对照，主候选选第三版，更接近撕裂笔刷方向

输出为真正1080×1440 PNG，不是把AI完整海报当成程序结果。资产中仅有固定标题或等级文字；日期、星期、百分比、圆环角度和时长由Canvas实时绘制。测试不写数据库或相册。

运行方式（仅隔离模拟器）：构建assembleDebugAndroidTest，在已有相同main APK的emulator-5554安装该测试包，然后运行cn.goff.shiben.test/cn.focusledger.LedgerInstrumentation，参数suite=lettering_study。输出位于目标应用files/qa-lettering-study，需通过该隔离模拟器的run-as读取。

当前只用于视觉确认。若确认方向，再按同一风格完成其余12种等级及区间标题，接入正式离线模板并重新做完整导出/内存/隐私验证。
