用户于 2026-10-05 批准 12 组、40 个页面/状态的目标概念，随后实施。PNG 为批准的概念图，不是运行截图。

## 实施范围

- 三个标签及其应用内子页统一原始背景、圆角半透明卡片、青绿按钮和原生线性图标。
- 专注页维持固定不滚动布局、原任务与时长选择、真实倒计时、暂停/继续/结束/完成流程。
- 任务保留创建、编辑、手动进度、两秒庆祝、排序、归档及放弃确认。
- 今日保留优先级权重、历史、导出、提醒设置、本地存储与备份。
- 系统通知权限、精确提醒、日期选择、文件夹选择和文件保存仍使用 Android 原生组件，不仿制系统权限 UI。
- PNG/Markdown 的数据、分页算法、完整性和存储格式保持不变；预览外框和应用内交互统一样式。

## 原始背景

应用使用用户提供的原图，原始字节不变，不从概念图裁切，不替换为新生成图。

- 专注：`drawable-nodpi/focus_backdrop.png`
- 任务及子页：`drawable-nodpi/tasks_backdrop.png`
- 今日及子页：`drawable-nodpi/today_backdrop.png`

nodpi 避免系统按密度放大源图引入额外内存开销。背景离线打包，不增加联网或分析依赖。
