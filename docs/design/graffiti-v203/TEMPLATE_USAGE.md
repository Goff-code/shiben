# 黑青涂鸦导出模板

当前是功能已验证、涂鸦视觉尚未确认的开发候选，不是正式冻结版本。

这是时本内置、可重复使用的图片导出模板。模板随已签名的正式更新安装，不需要单独把图片导入应用。

## 使用

1. 打开“今日” → “更多” → “导出记录”。
2. 选择“PNG图片”和日期或日期范围。
3. 想只展示日期、注意力总时长、完成度和等级时，开启“隐藏所有任务细节”。此时导出3:4海报；开关默认关闭，也会记住上次选择。
4. 点“预览导出”检查，再点“保存到相册”（Android10及以上）。Android8/9使用“保存图片文件”系统选址。

关闭隐藏开关会保留完整任务明细。单日很长时按页生成多张PNG；多日期汇总为一张长PNG，超过安全范围会明确提示，不会偷偷裁掉内容。

## 自动内容

- 单日：记录日期和星期、总注意力时长、当天总完成度、当天等级
- 日期范围：起止日期（全部范围显示实际首尾记录）、累计时长、每日总完成度平均值、按原规则计算的区间等级
- 0%、未知、长日期范围、较长时长以及S至SSS+等不同长度等级均走同一离线模板

单日100%时原有手动等级选择继续有效；区间按实际平均完成度重新计算，不继承某天的SSS+。无记录日期不补0，未知日期进度不偷换成已知日期均值。

模板的摄影底不含固定日期、等级、百分比或时长。图片中的示例数据只是开发预览；以后导出使用应用中的真实记录。首次与以后导出均不需要联网，也不需要AI生成图片。

## 开发者复用

共用渲染器：`app/src/main/java/cn/focusledger/GraffitiPoster.java`。

原生接入：单日由`ExportWorker`调用`drawDay`，多日期由`RangeSummaryRenderer`调用`drawRange`。摄影底保存在`res/drawable-nodpi/export_graffiti_studio.png`；中文字型为`res/font/ma_shan_zheng.ttf`，许可在`assets/licenses/MaShanZheng-OFL.txt`。标题与数值均动态绘制，等级为原创矢量路径。

APK是否已正式签名及可覆盖安装，以本次发布校验说明为准。不要安装Debug包覆盖正式数据，也不要卸载旧版或清除数据。
