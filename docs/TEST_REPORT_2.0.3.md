## 汇总规则与边界

- 日期范围包含起止日，只纳入真实留存的日期；没有记录的日期不按0%补齐。输入顺序不影响统计结果，相同日期重复输入明确拒绝。
- 每日总完成度的算术平均作为区间完成度；保留未取整值判等级。浮点转换也不能让边界下方均值提前升档；60/70/80/84/87/90/94/97门槛及nextDown均已测试。
- 任一留存日总进度未知时，均值和等级显示未知，并显示已知/未知天数；不偷偷换成仅已知日期的平均。任务级未知同样不当0或跳过。
- 真正每日全部完成才允许汇总S；不平均字母等级、不继承单日手动SS/SSS/SSS+。单日原有手动等级保留。
- 任务以稳定ID跨日合并，最后日期名称用于显示，同名不同ID不合并；任务未出现的日期不补0。归档行作为原始留存证据纳入任务汇总，不更改每日总进度。
- 长时长溢出拒绝；真实Paint/Bitmap验证0001–9999年份和Long.MAX_VALUE累计时长不会越界。Unicode代理对完整保留。
- 普通汇总图1080宽、最高8000，共8.64M像素；ARGB输出34,560,000字节、背景最多2,097,152字节，加8MiB辅助余量为45,045,760字节，低于48MiB预算。背景关闭密度缩放、先读bounds并校验实际分配。
- 超限在图像/相册写入前预检，明确提示缩小范围或Markdown；没有截断任务、拆多张或改ZIP。
