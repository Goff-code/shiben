# 时本 2.0.3 升级说明

## 安装身份与数据

- 包名仍为 `cn.goff.shiben`，versionName `2.0.3`、versionCode `6`；Android API26 至35目标保持不变。
- 必须沿用既有V2正式证书：SHA256 `af1c11b14290abcd0aa95dfa3284ce931a822751f2780293f0aab9c90cce59d5`。未签名APK不能直接安装；Debug不是给用户覆盖正式包的安装文件。
- 数据库schema仍为3；本版没有数据库迁移，不改计时、任务、历史、手动结算或Markdown算法。直接覆盖安装，不要卸载或清除数据。
- 云端只负责开发和验证；私钥、签名密码不进入源码或云端。

## PNG保存

Android10及以上点击“保存到相册”，将真实PNG写入系统媒体库的 `Pictures/时本/`，供相册/图片应用查看。不再输出ZIP，也不是只改后缀。

- 单日正常明细保持原布局与完整分页，每一页都是独立PNG，一次保存整组图片。
- 多日期正常明细汇总成单张长图，显示选择范围、实际留存日期数、累计注意力、每日总完成度平均值、区间等级和任务汇总。
- 多日期均值只计算有记录的日期；无记录日期不补0。留存日进度未知时不偷偷排除或补0，区间均值和等级显示未知，说明未知天数。
- 任务按稳定任务ID合并，同名不同任务保持独立；名称取最后日期留存值，每项显示其有记录日期的平均完成度和累计实际注意力。改名、归档或未知旧记录不改写原始历史。
- 多日期等级按未取整均值使用现有门槛自动判定；全部真实完成时为S，不继承某日手动SS/SSS/SSS+。单日继续保留当日实际等级。
- 多日期完整明细上限为1080×8000像素，并预检包含输出、背景与辅助余量的48MiB预算。极长任务超限会明确要求缩小范围或改用Markdown；不会暗中截断、压成不可读小字或改为ZIP。
- 相册写入先保持pending，全部内容成功写完才发布；取消或失败清理本批新建项目，不影响此前保存的相片。重复点击及页面重建不会重复保存同一成功批次。
- Android8/9保留“保存图片文件”系统选址，每页单独保存，不冒称直接入相册。本次没有增加任何照片、存储或网络权限。

## 隐藏所有任务细节

PNG格式下新增“隐藏所有任务细节”开关，默认关闭，可以记住用户选择。开启后单日和多日期都输出紧凑单张，只保留日期/范围、总注意力时长、总完成度和结算等级；多日期附实际统计天数。任务名称、每项任务数值和任务说明不绘制，文件名不含任务名称。隐藏模式不会保留空白分页，也不受明细长度的图片上限影响。

此开关不改用户历史，也不影响Markdown内容。PNG是一张可阅读的记录，不是可恢复数据库备份。
